## Plan: Per-repo-card collapse button with persistent state

### Goal
Add a collapse/expand button at the far right of each `GitRepoCard`'s action bar (after the Refresh button). When collapsed, the card's body content (error banner, commit box, file groups) is hidden — only the header remains. State is persisted per repo path in the settings table so it survives app restarts.

### Files to modify (3 files)

---

### 1. `packages/contracts/src/ipc.ts`

Add a new setting key constant (alongside the other `UI_*_SETTING_KEY` constants at ~line 146):

```ts
/** Setting key for per-repo collapsed state in the Git panel. Value is a
 *  JSON-encoded `Record<string, boolean>` mapping repo paths to collapsed
 *  state. Persisted so the collapsed/expanded state survives restarts. */
export const UI_GIT_COLLAPSED_REPOS_SETTING_KEY = "ui.gitCollapsedRepos";
```

### 2. `apps/desktop/src/renderer/stores/sessionStore.ts`

**C. Add action type** in the store interface (~after `setCommitGenPrompt`):

**D. Hydrate in `init()`** — read the setting during hydration (around ~line 1315, alongside other IDE/Git settings):

```ts
const collapsedRes = await api.setting.get({ key: UI_GIT_COLLAPSED_REPOS_SETTING_KEY });
ctx.collapsedGitRepos = collapsedRes.value
  ? JSON.parse(collapsedRes.value) as Record<string, boolean>
  : {};
```
(This should be added as a separate try/catch after the existing IDE/Git hydration block at ~lines 1357.)

**E. Implement action** — add `toggleCollapsedGitRepo` alongside the other setters (~line 2838, after `setCommitGenPrompt`):
```ts
toggleCollapsedGitRepo: (repoPath) => {
  set((s) => {
    const next = { ...s.collapsedGitRepos };
    if (next[repoPath]) {
      delete next[repoPath]; // remove key when expanding
    } else {
      next[repoPath] = true;
    }
    void api.setting
      .set({ key: UI_GIT_COLLAPSED_REPOS_SETTING_KEY, value: JSON.stringify(next) })
      .catch((err) => console.error("setting.set(gitCollapsedRepos) failed:", err));
    return { collapsedGitRepos: next };
  });
},
```
