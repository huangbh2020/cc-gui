# 模型设置页整合 + 组件库排版重构

把「模型配置」(claude) 和「Pi 模型」(pi) 两页合并成一页(左侧统一列表 + 类型徽标),凭据支持**眼睛图标临时显示明文**,Pi 的 contextWindow 改为**是否 1M 开关**(默认 200k),并**全面用组件库 + 图标库重写排版**(替换原始 `<input>`/`<select>`/`<button>` 和 Unicode 字符)。

## 1. 后端:新增 claude 侧"取明文 token"IPC(pi 复用现有 getApiKey)

### `packages/contracts/src/ipc.ts`
- 新增 `GetCustomModelTokenSchema = z.object({ id: z.string().min(1) })` → `{ token: string | null }`
- `IPC` 加 `CUSTOM_MODEL_GET_TOKEN: "customModel:getToken"`
- `RpcMap` 加 `"customModel.getToken": (input) => Promise<{ token: string | null }>`
- 注释:明文回传,**仅限用户主动点眼睛查看**,不可用于后台逻辑

### `apps/desktop/src/main/ipc/customModel.ts`
- 新增 handler,复用现成的 `CustomModelStore.resolveApiConfig`(main 内存有明文 authToken):
  ```ts
  ipcMain.handle(IPC.CUSTOM_MODEL_GET_TOKEN, (_evt, raw) => {
    const { id } = GetCustomModelTokenSchema.parse(raw);
    return { token: CustomModelStore.resolveApiConfig(id)?.authToken ?? null };
  });
  ```

### `apps/desktop/src/preload/index.ts`
- `customModel` 加 `getToken`;`piModels` 补 `getApiKey`(IPC 已注册但 preload 一直没暴露)

## 2. 契约:Pi contextWindow → 1M 开关

### `packages/contracts/src/piModel.ts`
- 新增常量 `PI_DEFAULT_CONTEXT_WINDOW = 200_000`、`PI_1M_CONTEXT_WINDOW = 1_000_000`
- `PiModelDefinition.contextWindow` 字段保留(仍是 models.json 真实字段),只是 UI 改由开关二选一写入

## 3. 前端:合并为单一 CustomModelsPanel + 全面组件库化

### `SettingsPage.tsx`
- 删 `pi-models` nav item 和 `SectionId` 中的 `"pi-models"`;只保留「模型配置」一项,渲染 `<CustomModelsPanel />`

### `ModelDropdown.tsx:68`
- `manageTarget` 改为 `(isPi || isClaude) ? "custom-models" : null`(两类都跳合并页)

### `CustomModelsPanel.tsx`(承载两类,全面重写排版)

**组件库映射表(替换全部原始元素)**:
| 现状 | 改为 |
|------|------|
| `<input type="text" className={inputCls}>` | `<Input />`(base-ui,自带聚焦/边框/字体) |
| `<input type="password">` | `<Input type="password">` + 眼睛按钮(新 SecretInput) |
| `<select>`(API 格式/认证方式/API 类型/思考级别) | `<Select.Root><Select.Trigger><Select.Value>…<Select.Item>` |
| `<button>`(新增/删除/保存/取消/测试) | `<Button variant=… size=…>` |
| 手写删除确认 `<Dialog.Root>` ×2 | `<ConfirmDialog>`(已有封装,统一文案/样式) |
| `▶` 高级选项折叠箭头 | `<IconChevronRight>` + rotate(类 FileTree 风格) |
| `●` 测试角色圆点 | 小色块 `<span>` 或保留圆点但用语义 token(accent 已是语义色) |
| 重复的手写 `Toggle` ×2 | 提取一份共享 `Toggle`(同文件内,role="switch" 保留) |
| 重复的手写 `Field` ×2 | 提取一份共享 `Field` |

**布局结构(排版优化)**:
```

│ 模型配置  [Claude 端点 / Pi Provider 统一]   │

│ [+ Pi Provider]  │                            │

└──────────────────┴────────────────────────────┘
```
- 左侧列表:`ListItem = {kind:"claude"|"pi", id, name, sub}`,每项左侧色条 + **类型徽标**(`[C]`/`[Pi]`,用 `text-accent`/`text-content-muted` 语义 token)。选中项保留现有 accent 色条。
- 两个「+ 新增」按钮用 `<Button variant="outline" size="sm">` + `IconPlus`,放列表底部。
- 右侧空态用图标 + 引导文案。

**ClaudeProviderForm**(从原 ProviderForm 改造):
- API 格式 / 名称 / Base URL / 认证方式 → `<Input>` + `<Select>`
- **Token / API Key → 新 `<SecretInput>`**(见下)
- 角色绑定表:5 行,保留 grid 布局;输入框换 `<Input>`,`●` 圆点按钮换语义色块;1M 列用共享 `Toggle`
- 高级选项折叠:`<IconChevronRight>` rotate
- 底部操作行:`<Button>` 测试/删除/取消/保存

**PiProviderForm**(从原 PiModelsPanel 表单改造):
- Provider 名称 / API 类型 / Base URL → `<Input>` + `<Select>`
- **API Key → `<SecretInput>`**
- authHeader → 共享 `Toggle`
- 模型列表行:模型 id/最大输出 → `<Input>`;**「上下文」输入框 → `<Toggle>` + 「1M 上下文」标签**(tooltip:"关闭=200k")
  - `ModelFormState.contextWindow: string` → `enable1m: boolean`
  - `modelFromDef`:`def.contextWindow >= 1_000_000 ? true : false`
  - `configFromForm`:`enable1m ? PI_1M_CONTEXT_WINDOW : PI_DEFAULT_CONTEXT_WINDOW`
  - 删除 contextWindow 数值校验(开关无需校验)
- 思考级别折叠:`<IconChevronDown>`/`<IconChevronRight>`(已有)

**新 `<SecretInput>` 组件**(两套表单共用,放本文件):
- props:`value`,`onChange`,`placeholder`,`mode`("create"|"edit"),`onReveal`(异步取明文回调)
- `<Input type={revealed?"text":"password"}>` + 眼睛 `<Button variant="ghost" size="icon">`(`<IconEye>`/`IconEyeOff>`)
- 点眼睛 → 调 `onReveal()`(父级按类型调 `customModel.getToken` / `piModels.getApiKey`)→ 回填明文 + `revealed=true`
- **新建模式**:明文已在表单,眼睛只切 `type`,不调 IPC
- **编辑模式**:默认空(留空=保持现有);点眼睛取明文回填;`onBlur` 或切选时 reset `revealed=false` 并清空回填(回到"留空=保持"语义)
- 用 `<Tooltip>` 给眼睛按钮加提示"显示/隐藏明文"

**删除确认**:两处手写 Dialog 换 `<ConfirmDialog>`(已有组件,统一标题/描述/危险按钮样式)。
