## 改造目标
把当前单页、英文的 `SettingsModal`(`apps/desktop/src/renderer/components/settings/SettingsModal.tsx`)改造成「左侧功能菜单 + 右侧内容面板」的中文设置页。点击右上角 ⚙ 仍通过现有 `settingsOpen` store 标志打开,无需改 TopBar / store / IPC / 契约。

## 关键事实(已确认)
- `ClaudePathPanel.tsx`、`CustomModelsPanel.tsx` 已作为独立、中文本地面板写好(注释明说「Extracted … so the modal can host it as one pane among several in a left-nav layout」),只是没被 `SettingsModal` 引用 —— 本次只需接线 + 改外壳。
- 两个面板各自管理 save/cancel/test 状态,Cancel/Save 都调用 `setSettingsOpen(false)`。`ClaudePathPanel` 在 mount 时 `useEffect` 加载当前值(设计为每次切换导航时重新挂载)—— 因此采用**条件渲染**(mount/unmount)而非 keep-alive。
- `settingsOpen` / `setSettingsOpen` 已在 sessionStore(line 61/151/543),无需改 store。

## 实现方案

### 1. 重写 `SettingsModal.tsx`(核心改动,唯一要改的现有文件)
新结构:

```
外层 backdrop(fixed inset-0 bg-black/60,点击关闭,不变)
└─ 容器: w-[760px] h-[520px] max-w-[92vw] max-h-[88vh]  rounded-lg border bg-surface shadow-2xl
   ├─ Header: 「设置」标题 + ✕ 关闭(border-b,不变样式)
   └─ Body: flex (左 nav w-52 + 右 content flex-1,中间 border-r)
      ├─ 左 nav:
      │   扁平菜单项列表(本地 useState `active`,默认 "claude-path"):
      │     • 通用          (placeholder)
      │     • Claude CLI 路径  (→ ClaudePathPanel)
      │     • 自定义模型      (→ CustomModelsPanel)
      │     • 外观          (placeholder)
      │     • 关于          (placeholder)
      │   项样式:px-3 py-2 text-xs rounded,active 时 bg-surface-muted + 左侧 accent 竖条 + text-content,非 active 为 text-content-muted hover:bg-surface-hover
      └─ 右 content: px-5 py-4 overflow-y-auto
          按 `active` 条件渲染对应面板/占位符
```

- 保留 Esc 关闭、backdrop 点击关闭、`open` 为 false 时返回 null。
- `active` 切换时由于条件渲染,旧面板卸载、新面板挂载 —— `ClaudePathPanel` 的 mount effect 自然重载,符合其设计。
- 占位项渲染一个内联 `PlaceholderPanel`(在 SettingsModal.tsx 内部定义的小函数组件):居中显示「该功能正在开发中」+ 一个 SVG/emoji 图标 + 简短副文案,使用 `text-content-subtle` 等现有 token。

### 2. 文件清单
- 改:`apps/desktop/src/renderer/components/settings/SettingsModal.tsx`(完全重写正文,保留对外签名 `export function SettingsModal()`)
- 不改:`TopBar.tsx`、`App.tsx`、`sessionStore.ts`、`ClaudePathPanel.tsx`、`CustomModelsPanel.tsx`、任何 main / contracts / IPC 文件、styles.css
- 不新增文件(PlaceholderPanel 内联)

### 3. 验证
1. `cd apps/desktop && npx tsc --noEmit -p tsconfig.json` —— 必须 0 error(strict)。
2. 启动 `pnpm dev`,点 TopBar ⚙ 打开设置:确认左侧菜单 5 项、右侧默认显示 Claude CLI 路径面板;点「自定义模型」切到该面板且能正常 test/save;点「通用/外观/关于」显示占位;Esc 与背景点击关闭正常;点 Cancel/Save 关闭正常。

## 风险/取舍
- 切换 nav 时若有未保存输入会丢失(与现状一致:Cancel 本就丢弃),不在本次扩展为「未保存提示」。
- 两个面板各自带 footer save/cancel,而非全局底部 footer —— 保留以最小化改动与面板自包含性。
- 占位项无功能,只占位(符合用户选择「已实现2项 + 占位项」)。
