# 功能开发计划：点击Tab定位线程 + 线程右键菜单

## 概述

两个功能：
1. **点击中间面板 Tab → 展开左侧对应项目 + 滚动定位到对应线程行**
2. **左侧线程行右键菜单**：重命名 / 复制会话标题 / 在文件管理器中打开项目目录（保留现有 hover 归档/删除按钮）

---

## 功能1：点击 Tab 定位左侧线程

### 问题根因
点击 tab 调 `selectSession`（`sessionStore.ts:2009`），内部 `syncConfigFromSession`（`:831`）会切 `activeProjectId`，但**不写 `expandedProjects`**（`:859` 只在 `prevPid !== projectId` 时刷新 sessions 派生视图）。`SessionRow`（`LeftBar.tsx:347`）也没有 ref，无法 `scrollIntoView`。若目标项目折叠或目标线程不在已加载的 5 条分页内，左侧无法定位。

### 改动

**A. `sessionStore.ts` — `syncConfigFromSession` 展开目标项目**
在 `:859` 的项目切换分支里（或无条件），把 `expandedProjects[sess.projectId] = true` 并入 `patch`。这样 `selectSession` / `openTab` / `rewindTurn` 所有激活路径都会展开目标项目，职责集中在数据层。需保留其他项目的展开状态（用 `...s.expandedProjects` 展开）。

**B. `LeftBar.tsx` — 行节点注册表 + 滚动定位 effect**
仿 `SessionTabs.tsx:60,85-92,177-180` 的 `tabNodes` 模式：
1. 顶层新增 `const rowNodes = useRef<Map<string, HTMLLIElement>>(new Map())`，`registerNode = useCallback((id, el) => { if (el) map.set(id, el); else map.delete(id); }, [])`。
2. `SessionRow` 接收 `registerNode` prop，挂到 `<li ref={(el) => registerNode(session.id, el)}>`。
3. 新增 effect 监听 `activeSessionId` 变化：
   - 已在 `rowNodes`：直接 `scrollIntoView({ block: "nearest", behavior: "smooth" })`。
   - 不在 DOM：用 `useSessionStore.getState()` 读最新 `sessionsByProject`，确认目标 session 是否已加载；若未加载且 `sessionsHasMoreByProject[pid]` 为真，循环 `await loadMoreSessions(pid)`（每次 5 条）直到包含目标 id 或 hasMore=false；每次 await 后检查 `rowNodes` 是否出现目标节点，出现即滚动。
   - 用 `let cancelled = false` + cleanup 防竞态（连续切 tab 时旧请求作废）。
   - `findProjectIdOfSession`：遍历 `sessionsByProject` 找含目标 id 的项目（或直接从 session 对象的 `projectId` 字段——但 effect 只有 id，故遍历）。

**C. 边界处理**
- 左侧面板关闭（`leftOpen=false`）时 `LeftBar` 不挂载，effect 不跑，无副作用。
- `activeSessionId` 为 null 时跳过。
- 滚动用 `block: "nearest"` 避免强行居中打乱用户视野（与现有 scrollIntoView 用法一致）。

## 功能2：线程右键菜单

### 2.1 重命名 IPC（全链路新增）

底层 `SessionRepo.updateTitle(id, title)` 已存在（`repositories.ts:252`），只缺通道。

- **`packages/contracts/src/ipc.ts`**：
  - 新增 `RenameSessionSchema = z.object({ id: z.string(), title: z.string().min(1).max(200) })` + `type RenameSessionInput`。
  - `IPC` 常量加 `SESSION_RENAME: "session:rename"`（`:1062` session 组内）。
  - `RpcMap` 加 `"session.rename": (input: RenameSessionInput) => Promise<{ session: Session }>`。
- **`apps/desktop/src/main/ipc/projects.ts`**：加 handler `ipcMain.handle(IPC.SESSION_RENAME, ...)`，`RenameSessionSchema.parse` 校验 → `SessionRepo.updateTitle` → `SessionRepo.get` 返回 `{ session }`（仿 `SESSION_ARCHIVE` handler `:75-82`）。
- **`apps/desktop/src/preload/index.ts`**：`api.session` 加 `rename: ((input) => ipcRenderer.invoke(IPC.SESSION_RENAME, input))`（仿 `archive` `:48-49`）。
- **`sessionStore.ts`**：新增 `renameSession(id, title)` action：调 `api.session.rename` → 用返回 session 更新 `sessionsByProject[pid]` 对应行的 title（若该 session 在已加载页内）→ 若是 `activeSessionId` 同步刷新派生视图。`SessionState` 接口（`:446-564`）声明该方法。

### 2.2 打开项目目录 IPC（全链路新增）

- **`packages/contracts/src/ipc.ts`**：`IPC` 加 `SHELL_OPEN_PATH: "shell:openPath"`；`OpenPathSchema = z.object({ path: z.string() })`；`RpcMap` 加 `"shell.openPath": (input: { path: string }) => Promise<void>`。
- **`apps/desktop/src/main/ipc/shell.ts`**（新文件）：`import { shell } from "electron"`，`registerShellHandlers(ipcMain)`，handler 校验传入 path 等于某个 `ProjectRepo.list()` 的 `project.path`（防任意路径打开），通过则 `await shell.openPath(path)`（返回错误串时 log 警告）。结构仿 `app.ts:14-23`。
- **`apps/desktop/src/main/ipc/index.ts`**：`registerIpcHandlers()` 内加 `registerShellHandlers(ipcMain);`（仿 `:14-21`）。
- **`apps/desktop/src/preload/index.ts`**：加 `shell: { openPath: ((input) => ipcRenderer.invoke(IPC.SHELL_OPEN_PATH, input)) as RpcMap["shell.openPath"] }`。

### 2.3 右键菜单组件（base-ui 受控 Menu + 虚拟坐标 anchor）

依据探索结论，base-ui `ContextMenu.Trigger` 锚定元素而非鼠标坐标，不满足"在鼠标点弹出"。采用**受控 `Menu.Root` + 虚拟元素 `anchor`** 方案（`Menu.Positioner` 的 `anchor` prop 接受 `VirtualElement`，其 `getBoundingClientRect` 返回鼠标坐标的零尺寸 rect）。

- 在 `LeftBar.tsx` 顶层管理 `const [ctxMenu, setCtxMenu] = useState<{ sessionId: string; x: number; y: number } | null>(null)`。
- `SessionRow` 的 `<li>` 加 `onContextMenu={(e) => { e.preventDefault(); onContext(session, e.clientX, e.clientY); }}`（新增 `onContext` prop 透传）。
- 新增 `SessionContextMenu` 组件（同文件内或单独文件）：
  - `Menu.Root open={!!ctxMenu} onOpenChange={(o) => { if (!o) setCtxMenu(null); }}`
  - `anchor = useMemo(() => ({ getBoundingClientRect: () => ({ x, y, top: y, left: x, bottom: y, right: x, width: 0, height: 0, toJSON: () => ({}) }) }), [coords])`
  - `Menu.Portal > Menu.Positioner anchor={anchor} side="bottom" align="start" > Menu.Popup`
  - Popup 样式复用 `SessionTabs` OverflowMenu 的 class（`z-50 ... shadow-2xl ...` + `data-[highlighted]` 高亮）。
- 菜单项（共3项，用户已确认）：
  1. **重命名**（`IconPencil`）→ 打开重命名对话框。
  2. **复制会话标题**（`IconCopy`）→ `navigator.clipboard.writeText(session.title)`（renderer 直接可用，无需 IPC）。
  3. **在文件管理器中打开项目目录**（`IconFolder`）→ 从 session.projectId 查 project.path → `api.shell.openPath({ path })`。
- 菜单关闭后清空 `ctxMenu`。菜单项 onClick 里先 `setCtxMenu(null)` 关闭再执行动作（避免对话框被遮）。

### 2.4 重命名对话框（仿 TerminalCommandsMenu 输入框 Dialog 范式）

照搬 `TerminalCommandsMenu.tsx:148-200` 的 `Dialog.Root`(受控) + `Portal/Backdrop/Popup` + `Title/Description` + 受控 `Input`(autoFocus) + 底部取消/保存 `Button`。

- `LeftBar` 顶层管理 `const [renaming, setRenaming] = useState<{ id: string; title: string } | null>(null)`。
- 输入框预填当前 `title`，`autoFocus` + 选中全文本（`e.target.select()`），Enter 提交、Esc 取消。
- 空标题禁用保存按钮（`disabled={!trim}`）。
- 提交调 `renameSession(id, trim)` 后关闭对话框。
- 若该 session 正在运行（`runningBySession[id]`），重命名仍允许（title 改动不影响 turn）。

## 验证方式

1. **类型检查**：`cd apps/desktop && npx tsc --noEmit -p tsconfig.json`（contracts + desktop 都过）。
2. **手动验证**（`pnpm dev`）：
   - tabs 模式：折叠某项目 → 点该项目的 tab → 左侧自动展开并滚动高亮到线程行。
   - 目标线程在第 8 条（第 2 页）→ 点 tab → 自动加载更多并滚动到位。
   - 右键线程 → 菜单在鼠标坐标弹出 → 重命名（Enter/Esc/空标题禁用）、复制标题（粘贴验证）、打开目录（资源管理器弹出）。
   - hover 归档/删除按钮仍正常。
   - single 模式同样验证定位生效。
3. **安全验证**：尝试用篡改的 path 调 `shell.openPath`（非项目路径）→ main 拒绝并 log。

## 不做的事

- 不给线程行加固定/收藏（需新 DB 列 + 迁移，用户未要求）。
- 不改 hover 归档/删除按钮（保留）。
- 不持久化 `expandedProjects`（现有设计即不持久化，保持一致）。
- 不在右键菜单放归档/删除（用户未选，hover 已覆盖）。
