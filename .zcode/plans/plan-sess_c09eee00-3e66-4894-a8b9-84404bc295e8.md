## 目标

发送含粘贴卡片的消息后，聊天区域里用户消息也要保持和输入框一致的卡片形态——在消息左上方显示「复制内容卡片」（accent 主题色 + 可点击预览），而不是把粘贴内容混在一整段文字里。

## 现状（已确认）

- `handleSend`（ChatPane.tsx:456）把 tags 通过 `composePromptWithTags` 合并成**纯文本** prompt，tags 元数据丢失
- `sendPrompt(prompt: string)`（sessionStore.ts:1142）只接收纯文本，创建 user 消息时 blocks 只有一个 `{ kind: "text" }`
- 聊天区渲染只能看到合并后的一整段文字，无法还原卡片

## 方案：新增 `attachment` block

在 `Block` 联合类型里加一个 `attachment` variant，承载卡片的 preview + content。这样卡片成为 user 消息的一等组成部分，渲染、复制、持久化都自然走通。

## 改动范围（4 个文件）

### 1. 数据模型 — `sessionStore.ts`
- `Block` 联合新增：
  ```ts
  | { kind: "attachment"; preview: string; content: string }
  ```
- `sendPrompt` 签名改为接收可选的 attachments：
  ```ts
  sendPrompt: (prompt: string, attachments?: { preview: string; content: string }[]) => Promise<void>;
  ```
- `sendPrompt` 实现里创建 user 消息时，把 attachments 转成 `attachment` blocks **排在 text block 之前**（卡片在上、文字在下，与输入框布局一致）
- **持久化无需改动**：`toRecords`/`fromRecords`（L293-325）对 `Block[]` 透明透传为 JSON，新 kind 天然支持

### 2. 发送链路 — `ChatPane.tsx`
- `handleSend`：不再丢弃 tags，改为把它们映射成 `{ preview, content }[]` 传给 `sendPrompt`
  ```ts
  const attachments = tags.map(t => ({ preview: t.preview, content: t.content }));
  void sendPrompt(prompt, attachments.length > 0 ? attachments : undefined);
  ```

### 3. 渲染层 — `MessageBlocks.tsx`
- `groupBlocks`：`attachment` 块像 `text`/`error` 一样 flush 当前的 procedural run，并作为 `single` 段渲染（不并入 ProceduralGroup）
- `BlockView` 的 switch 新增 `attachment` 分支 → 渲染复用输入框同款卡片样式
- **新增 `AttachmentCard` 组件**（在 MessageBlocks.tsx 内）：复用 ContentTagChip 的视觉风格（accent 主题色、IconClipboard、rounded-md border），但点击预览用同文件的轻量 Collapsible 展开（聊天区不依赖 TagPopover 的 fixed 定位，用就地展开更稳定）
  - 折叠态：`[IconClipboard] preview` + chevron
  - 展开态：显示完整 content（可滚动、monospace）+ Copy 按钮
  - 无边框（与之前 procedural 卡片去边框的改造一致）

### 4. 复制 & 时间线 — `ChatPane.tsx` + `MessageTimeline.tsx`
- 两处 `blocksToText` 都加 `attachment` 分支：把 content 拼进复制/时间线文本（格式参考 composePromptWithTags 的 delimited block，保持一致）

## 不改动的部分

- 持久化层（toRecords/fromRecords）
- sendTurn IPC 契约（prompt 仍是合并纯文本，attachments 只影响**本地 user 消息的展示**，不发给后端）
- ContentTagChip / TagPopover（输入框侧不变）

## 验证

1. `npx tsc --noEmit -p tsconfig.json` 通过
2. `pnpm dev`：粘贴一段长内容生成卡片 → 发送 → 确认聊天区用户消息左上方显示同款 accent 卡片，点击可展开预览/复制，文字部分在卡片下方
3. 回归：无卡片的纯文本消息渲染不变；复制用户消息时 attachment 内容正确包含；时间线标签正常
