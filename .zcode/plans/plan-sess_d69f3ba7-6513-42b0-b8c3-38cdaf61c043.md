# 实现「Git 文件打开方式」可配置(中间编辑器 / 弹框编辑器)

## 需求
1. 设置页可配置 git 面板点击修改文件的**打开方式**,两种:
   - **中间区域编辑器**(现状)
   - **弹框编辑器**(新):可同时打开多个 diff tab;关闭弹框后,界面上有**明显按钮**可重新进入弹框(选定位置:Git 面板顶部工具栏,仅当有打开的 diff tab 时显示)。

## 设计概要

新增一个持久化设置 `ui.gitDiffOpenMode`(`"center" | "dialog"`,默认 `"center"`,对齐现有 `ui.displayMode` / `ui.ideEditorMode` 模式)。弹框模式下,点击 git 文件不再走 `openFileInIde`,而是往 store 里一个新的 `gitDiffDialogTabs` 桶添加一个 tab(去重 + 激活),由一个独立的 `<GitDiffDialog>` 组件渲染成可多 tab 的 Monaco diff 弹框。

**复用现有 `DiffPane`**:把 `FileEditor.tsx` 中的 `DiffPane`、`useMonacoTheme`、`languageForExt` 导出(`FileEditor` 内部继续用),弹框里直接 `<DiffPane filePath before after />`,零重复实现,且继承了它已解决的 Monaco 卸载竞态处理。

## 改动清单

### 1. 契约层 `packages/contracts/src/ipc.ts`
- 新增 `UI_GIT_DIFF_OPEN_MODE_SETTING_KEY = "ui.gitDiffOpenMode"` + `GitDiffOpenModeSchema = z.enum(["center","dialog"])` + `type GitDiffOpenMode`。位置:紧挨 `UI_IDE_EDITOR_MODE_SETTING_KEY` 段落,带 JSDoc 说明(对齐该文件既有风格)。

### 2. store `apps/desktop/src/renderer/stores/sessionStore.ts`
- 导入新 key/类型。
- **状态字段**(紧跟 `ideEditorMode` 之后):
  - `gitDiffOpenMode: GitDiffOpenMode;` // 默认 `"center"`,持久化
  - `gitDiffDialogTabs: GitDiffDialogTab[];` // 弹框内已打开的 tab,按顺序;**非持久化**(ephemeral,重启清空)
  - `gitDiffDialogActiveId: string | null;` // 当前激活的 tab id
  - `gitDiffDialogOpen: boolean;` // 弹框显隐(关闭弹框不丢 tab,只是隐藏;有 tab 时工具栏按钮可重开)
  - 新增 `GitDiffDialogTab` 接口:`{ id: string; filePath: string; before: string; after?: string; title: string; repoPath: string; source: "working" | "history" }`
- **动作声明 + 实现**:
  - `setGitDiffOpenMode(mode)`:set + fire-and-forget `api.setting.set`(对齐 `setIdeEditorMode` 的写法)。
  - `openGitDiffDialogTab(tab)`:去重(同 `filePath` 只保留一个,复用其 id 并刷新 before/after/title),追加到末尾,设为 active,`gitDiffDialogOpen=true`。
  - `closeGitDiffDialogTab(id)`:移除 tab;若关的是 active 则切到相邻 tab;若列表空则 `gitDiffDialogOpen=false`、`activeId=null`。
  - `setGitDiffDialogActive(id)`、`setGitDiffDialogOpen(open)`:纯 set。
- **init() 水合**:在 IDE pref 的 `Promise.all` 里加一项 `api.setting.get({ key: UI_GIT_DIFF_OPEN_MODE_SETTING_KEY })`,校验 `"center"|"dialog"` 后 set(对齐 `ideEditorMode` 水合写法,在 line ~1567 附近)。默认值在 `initialState` 设 `"center"`。

### 3. 导出 `DiffPane` 等可复用件 `apps/desktop/src/renderer/components/ide/FileEditor.tsx`
- 把 `function DiffPane` → `export function DiffPane`。
- `export function useMonacoTheme`、`export function languageForExt`(供弹框复用;保持现有调用点不变)。
- 注:不导出 `EditPane`/hooks,只导出弹框需要的三个。

### 4. 新组件 `apps/desktop/src/renderer/components/ide/GitDiffDialog.tsx`
- 受控组件,读取 store 的 `gitDiffDialogOpen`/`setGitDiffDialogOpen`、`gitDiffDialogTabs`/`gitDiffDialogActiveId` 及对应动作。
- 用 `Dialog.Root open={gitDiffDialogOpen} onOpenChange={(o)=>setGitDiffDialogOpen(o)}` + `Portal`/`Backdrop`。
- `Dialog.Popup` 用大尺寸 `w-[90vw] max-w-[1400px] h-[85vh] max-h-[900px] flex flex-col p-0`,内部:
  - 顶部一行:标题 `查看差异` + 右上 `Dialog.Close`。
  - **Tab 条**(手写,模仿 `SessionTabs` 的 `border-b-2 border-accent` active 样式,`text-[11px]`):每个 tab 显示 `title`(basename)+ 关闭 `×`(hover 显,`IconX size={11}`)。横向可滚动(`overflow-x-auto`)。空列表时弹框本不该打开(防御:返回 null)。
  - 内容区 `flex-1 min-h-0`:渲染 active tab 对应的 `<DiffPane filePath={tab.filePath} before={tab.before} after={tab.after} key={tab.id} />`。
- 卸载安全:`DiffPane` 已内建 widget-then-models 的卸载顺序处理 + `key={tab.id}` 保证切 tab 重挂载。

### 5. 改造点击入口 —— 根据 `gitDiffOpenMode` 分流
两个入口,改法一致:若 `gitDiffOpenMode === "dialog"`,走新的 `openGitDiffDialogTab`;否则走原 `openFileInIde` 逻辑(完全不变)。

**`GitRepoCard.tsx` `FileRow.handleClick`(line 741)**:
- 先 `const gitDiffOpenMode = useSessionStore((s)=>s.gitDiffOpenMode)`(组件顶部已有的 store 订阅区加一行)和 `openGitDiffDialogTab`。
- 拿到 `before` 后(无论 patch 是否存在,失败也照旧 fall through):若 `dialog` 模式 → `openGitDiffDialogTab({ id: stableId(absPath), filePath: absPath, before, title: basename(file.path), repoPath, source: "working" })`;否则保持原 `openFileInIde(absPath, { diff: true })`。
- 右键菜单「查看 Diff」共用 `handleClick`,无需额外改;「查看源文件」(openFileInIde 非 diff)保持不变 —— 打开方式设置只影响 diff 打开。

**`GitHistoryView.tsx` `openFile`(line 111)**:
- 同样读 `gitDiffOpenMode` 与 `openGitDiffDialogTab`(用 `useSessionStore.getState()` 或 hook,此处现有代码用 `useSessionStore.getState()`,保持一致风格)。
- dialog 模式 → `openGitDiffDialogTab({ id, filePath: absPath, before, after, title: basename(file.path), repoPath, source: "history" })`;否则原 `setGitDiffPair` + `openFileInIde`。

### 6. Git 面板顶部「重新进入弹框」按钮 `GitPanel.tsx`
- 在 sub-tab 条(更改|历史)右侧那块 `ml-auto` 区域(`IconRefresh` 旁边),新增一个按钮:**仅当 `gitDiffDialogTabs.length > 0` 且 `gitDiffOpenMode === "dialog"` 时显示**。
- 样式:`flex items-center gap-1 rounded px-1.5 py-0.5 ... text-accent`(醒目),带角标 `gitDiffDialogTabs.length`。图标用 `IconEye`(与「查看 Diff」一致)或 `IconColumns3`(已在 icons 层)。点击 `setGitDiffDialogOpen(true)`。
- 即使当前在「历史」子 tab 也显示(顶部条对两个子 tab 都常驻)。

### 7. 挂载弹框 `App.tsx`
- 在工作区视图(`settingsOpen` 的 else 分支)内、与三栏并列,渲染 `<GitDiffDialog />`。它通过 Dialog Portal 挂到 body,位置不影响布局;自身 `open=false` 时不渲染 Popup。
- 导入 `GitDiffDialog`。

### 8. 设置页控件 `AppearancePanel.tsx`
- 在「中间面板显示模式」那一行**之后**,新增一行 SettingRow「Git 差异打开方式」,desc:「点击 Git 面板中的修改文件时,差异查看器的打开位置。」
- 控件用 `<Select.Root>` 绑定 `gitDiffOpenMode`/`setGitDiffOpenMode`,选项 `center`→「中间区域编辑器」、`dialog`→「弹框编辑器(可多标签)」。完全复刻「中间面板显示模式」那行的结构。
- 顶部 import `gitDiffOpenMode` 相关 store 选择器与类型。

> 放「外观」页而非「Git」设置页:它与「中间面板显示模式」同属布局/打开行为偏好,且 Git 设置页当前专注提交信息生成,语义更贴合 Appearance。`SettingRow` 已在用。

## 关键约束与对齐点(来自 AGENTS.md / 既有代码)
- **zod 校验**:本特性无新增 IPC 通道(复用通用 `setting.get/set`,已有 zod 校验),无需改 preload/handler。
- **class 合并**:新代码一律 `cn()`,语义 token(`bg-surface`/`text-content`/`border-edge`/`text-accent`/`text-content-muted`/`text-content-subtle`)。
- **图标**:用 `@renderer/lib/icons.js` 的 `<IconX>` 等,`size={16/12/11}`。
- **Zustand 稳定引用**:选择器返回标量/稳定值;`gitDiffDialogTabs` 用模块级 `EMPTY` 常量兜底 `?? EMPTY`(避免新 `[]` 触发无限渲染,遵守项目踩坑记录)。
- **Monaco**:复用 `DiffPane` 的卸载竞态处理;`monacoSetup` 已在 `FileEditor` 图中被 import,弹框经由 `DiffPane` 同处模块图,无需重复 side-effect import。
- **`absPath` 作为去重 key**:同一文件多次点击只占一个 tab,刷新其 before/after(避免 stale 左侧 pane)。
