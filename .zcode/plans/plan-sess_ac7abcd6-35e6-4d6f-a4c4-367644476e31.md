## 目标

解决设置面板"功能分类标题"（h2，`font-semibold` 14px）与"功能设置标题"（`SettingRow`，`font-medium` 12px）视觉区分不明显的问题。采用你确认的**卡片分组**方案（iOS/VS Code 风格）：分类标题变为小号灰色标签，设置项放入带边框的卡片，卡片内行间细分隔线，页面顶部保留大标题。

## 新增组件（组件库 components/ui + 设置专用 components/settings）

1. **`ui/card.tsx` → `Card`**：通用卡片容器，`rounded-lg border border-edge bg-surface`。
2. **`ui/switch.tsx` → `Switch`**：基于 `@base-ui/react/switch`（node_modules 已有）封装。Props: `checked / onCheckedChange / disabled / id / label(aria-label+title)`。视觉沿用现有手写 Toggle（`h-4 w-7` 圆角轨道 + `h-3 w-3` 滑块）。统一替换 4 个面板里重复的本地 `Toggle` 实现（NotificationsPanel / TitleGenPanel / LspLanguagesPanel / CustomModelsPanel）。
3. **`settings/PanelHeader.tsx`**：页面级大标题块。`title`（`text-base font-semibold`）+ `desc`（小号灰）+ 可选 `icon`（accent 色）+ 可选 `action`（右侧按钮槽，如快捷键面板的"恢复全部默认"）。
4. **`settings/SettingsSection.tsx`**：分类容器。分类标签（`text-[0.8571em] font-semibold text-content-muted` + 可选图标）+ 可选描述 + `<Card className="divide-y divide-edge">` 包住行设置。

层级：页面标题(16px 加粗) > 分类标签(12px 灰加粗) > 卡片内设置行(12px 常规 + 右侧控件)。

## 面板重构（全部改为统一结构）

| 面板 | 结构 |
|------|------|
| GeneralPanel | PanelHeader「常规」+ SettingsSection「布局」(显示模式/密度) + TitleGenPanel |
| TitleGenPanel | 改为渲染 SettingsSection「线程名称生成」，换用共享 Switch |
| AppearancePanel | PanelHeader「外观」+ Card（单分类直接入卡，无 eyebrow） |
| NotificationsPanel | PanelHeader「消息通知」+ Card + 共享 Switch |
| GitPanel | PanelHeader「Git」+ 3 个 SettingsSection（差异打开方式/提交记录生成/冲突解决） |
| TerminalPanel | PanelHeader「终端」+ SettingsSection（终端 Shell/自定义命令） |
| ShortcutsPanel | PanelHeader（action=恢复全部默认）+ 按 COMMAND_GROUPS 每个一组 SettingsSection |
| LspLanguagesPanel | PanelHeader「语言服务器」+ Card 语言卡片列表 + 共享 Switch |
| CustomModelsPanel / SkillsPanel / AboutPanel | 仅将顶部 h2 块替换为 PanelHeader，复杂双栏布局不动 |

## 背景调整（1 行）

`SettingsPage.tsx` 中心内容包裹层加 `bg-surface-muted`，让白色/深色 `Card` 从页面背景中浮出来（与主工作区"center 浮在 muted 轨道"的既有设计语言一致，light 白卡/muted 灰底、dark 深卡/浅灰底）。

`SettingRow` 行布局本身不动（已是合理布局），层级由 eyebrow + 卡片承担。
