# 为终端添加自定义命令功能

## 目标
用户可保存自定义命令(`{name, command}`),在终端工具栏通过下拉菜单一键快捷运行。所有管理(增/删/改)都在终端工具栏内联完成。

## 设计决策(已与用户确认)
- **管理入口**:终端工具栏内联管理——下拉菜单列命令(点击即运行)+ 菜单内编辑/删除 + 「添加命令」对话框。无需跳设置页。
- **执行方式**:立即执行——`api.terminal.write({ terminalId, data: command + "\n" })` 直接写入 PTY。
- **命令结构**:`{ name: string; command: string }` —— name 用于菜单显示,command 是实际命令。

## 架构对齐(基于代码探索)
- **持久化**:沿用 `setting.get/set` 通用键值表(`settings` 表是 `TEXT` key/value)。新增常量 `UI_CUSTOM_COMMANDS_SETTING_KEY = "ui.customCommands"`,值是 `JSON.stringify({name,command}[])`。无需改 IPC schema/handler/preload(`setting.set` 接受任意 string key + JSON 值)。
- **Store 模式**:照搬 `commitGenModel`/`commitGenPrompt` 的写法——store 字段 + setter(改 state + `void api.setting.set(...).catch()`),在 `init()` 的 `Promise.all` 批量 hydrate 里加一项 + 防御性 `JSON.parse` + `Array.isArray` 校验。
- **下拉菜单**:照搬 `EffortDropdown.tsx` 的 base-ui `Menu` 模式(`Menu.Root/Trigger/Portal/Positioner/Popup/Item`),`side="top"` 向上展开(底部栏场景)。复用共享的 `Menu.Popup` 样式 token。
- **命令执行**:在 `TerminalPanel` 已有的 `activeHandle?.getTerminalId()` 上调用 `api.terminal.write`,与现有 `activeHandle?.clear()` 等同一作用域。
- **图标**:`IconBookmark`(已导出,line 121)做命令菜单触发图标;`IconPencil`(line 88)做编辑;`IconPlus`(已有)做添加;`IconTrash`(已有)做删除。
- **对话框**:用 `Dialog`(base-ui,`@renderer/components/ui`),参考 `GitRepoCard` 的受控对话框模式(open/onOpenChange)。

## 实施步骤

### 1. `packages/contracts/src/ipc.ts` — 新增 setting key 常量 + 类型
在 `UI_GIT_COLLAPSED_REPOS_SETTING_KEY`(line 164)后面加:
```ts
/** 自定义终端命令。值为 JSON-encoded `{ name: string; command: string }[]`。 */
export const UI_CUSTOM_COMMANDS_SETTING_KEY = "ui.customCommands";
```
并在文件内定义一个共享类型供 store 与组件复用:
```ts
/** 一条用户保存的终端快捷命令。 */
export interface CustomCommand {
  id: string;       // 稳定 id(用于 React key + 编辑/删除定位)
  name: string;     // 显示名称,如「启动开发服务器」
  command: string;  // 实际命令,如 `npm run dev`
}
```
(`id` 字段是新增的,比纯 `{name,command}` 更利于编辑/删除时的稳定定位——我会加在类型里。)

### 2. `sessionStore.ts` — 新增 store 字段 + setter + hydrate
- **import**:`UI_CUSTOM_COMMANDS_SETTING_KEY` 和 `type CustomCommand`(加到现有的 contracts import 块,line 22-35 区域)。
- **接口字段**(line 270 `rightPanelTab` 附近):`customCommands: CustomCommand[];`
- **接口 setter**:`setCustomCommands: (cmds: CustomCommand[]) => void;`(也可更细粒度,但全量 setter 足够,组件层负责增删改逻辑)。
- **默认值**:`customCommands: [],`(line 1275 `rightPanelTab: "files"` 附近)。
- **setter 实现**(line 2926 `setCommitGenModel` 附近):
  ```ts
  setCustomCommands: (cmds) => {
    set({ customCommands: cmds });
    void api.setting
      .set({ key: UI_CUSTOM_COMMANDS_SETTING_KEY, value: JSON.stringify(cmds) })
      .catch((err) => console.error("setting.set(customCommands) failed:", err));
  },
  ```
- **hydrate**(在 line 1359 的 `Promise.all` 批量读取里加一项 `api.setting.get({ key: UI_CUSTOM_COMMANDS_SETTING_KEY })`,解构出 `cmdsRes`,然后):
  ```ts
  // 防御性解析:JSON 数组校验,过滤掉形状不对的项
  if (cmdsRes.value) {
    try {
      const parsed = JSON.parse(cmdsRes.value);
      if (Array.isArray(parsed)) {
        const valid = parsed.filter(
          (c): c is CustomCommand =>
            c && typeof c === "object" &&
            typeof c.name === "string" && typeof c.command === "string" &&
            typeof c.id === "string",
        );
        set({ customCommands: valid });
      }
    } catch { /* malformed JSON — keep default [] */ }
  }
  ```

### 3. 新建 `components/ide/TerminalCommandsMenu.tsx`(下拉菜单组件)
基于 `EffortDropdown` 的 base-ui Menu 结构。Props:
```ts
interface Props {
  /** 运行命令:把 command + "\n" 写入当前活动 PTY。由 TerminalPanel 提供。 */
  onRun: (command: string) => void;
}
```
内部:
- 从 store 读 `customCommands` + `setCustomCommands`。
- **Menu 结构**:
  - Trigger:`IconBookmark` 图标按钮(样式与 `IconBtn` 一致:`rounded p-1 text-content-subtle hover:bg-surface-hover hover:text-content`),`side="top" align="end"` 向上展开。
  - Popup 头部:标题「自定义命令」。
  - 命令列表(空时显示「暂无自定义命令」占位):每项 = 名称(主)+ 命令(次,truncate,等宽字体)+ 右侧 hover 显示 `IconPencil`(编辑)/`IconTrash`(删除)。点击行主体 → `onRun(command)` + 关闭菜单。
  - 分隔线 + 「+ 添加命令」项 → 打开添加对话框。
- **添加/编辑对话框**(受控 `Dialog`,复用 `GitRepoCard` 模式):
  - 两个字段:名称(`<Input>`)、命令(`<Input>` 或 `<textarea>`,用 textarea 支持长/多行命令)。
  - 「保存」→ 若是编辑则替换该 id,若是新增则追加(生成 id:`cmd-${Date.now().toString(36)}`)→ `setCustomCommands(...)` → 关闭。
  - 「删除」(仅编辑态)→ 过滤掉该 id → `setCustomCommands(...)` → 关闭。

### 4. `TerminalPanel.tsx` — 集成命令菜单
- **import** `TerminalCommandsMenu` + `api`。
- **新增 `runCommand` 回调**:
  ```ts
  const runCommand = useCallback((command: string) => {
    const id = activeHandle?.getTerminalId();
    if (id && activeHandle?.getStatus() === "running") {
      void api.terminal.write({ terminalId: id, data: `${command}\n` });
    }
  }, [activeHandle]);
  ```
- **在右侧操作工具栏**(line 188-214,清屏/终止/重开那一组)**最前面**插入 `<TerminalCommandsMenu onRun={runCommand} />`,与现有 IconBtn 视觉一致。
- **注意**:`api` 已在该文件未导入——需确认。`activeHandle` 在 line 125 已计算,在作用域内。

### 5. `icons.tsx` — 确认无需改动
`IconBookmark`、`IconPencil`、`IconPlus`、`IconTrash` 均已导出(line 121/88/24/27),无需新增图标。
