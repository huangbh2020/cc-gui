## 右侧边栏布局重构方案

### 目标
把右栏从"横向 tab 切换（文件/Git 顶部 tab strip）"重构为"常驻竖向图标栏 + 主面板区域"的 IDE 风格布局：
- 左侧一条窄的竖向图标栏（常显示），放文件、Git、浏览器三个图标
- 右侧主面板区域：点文件图标显示 FilesPanel，点 Git 图标显示 GitPanel，点浏览器图标打开全屏浏览器 overlay（逻辑不变）

### 改动文件清单

#### 1. `RightPanel.tsx`（核心重构）
- **新布局**：`<div className="flex h-full">` 横向排列
  - 左：竖向图标栏 `<div className="flex w-12 shrink-0 flex-col items-center gap-1 border-r border-edge py-2 bg-surface-muted">`
    - 三个图标按钮（文件 `IconFolder`、Git `IconGitBranch`、浏览器 `IconWorld`），每个 `size={20}`
    - 文件/Git 按钮：active 时 `bg-accent/15 text-accent`，点击 `setRightPanelTab(id)`
    - 浏览器按钮：点击调 `setBrowserPanelOpen(true)`；用 `browserPanelOpen` 控制 active 高亮；用 `browserTabCount > 0` 显示角标
    - 沿用现有 `hintFor` 快捷键提示逻辑（把 `layout.toggle-browser` 的 chord 拼到浏览器按钮 title）
  - 右：主面板区域 `<div className="relative min-h-0 flex-1 overflow-hidden">`
    - `{tab === "files" && <FilesPanel />}`
    - `{tab === "git" && <GitPanel />}`
    - （浏览器不在此渲染——它是全屏 overlay，仍在 App.tsx 顶层渲染）
- 移除原 `TABS` 常量和横向 tab strip，改用显式的三个按钮（因为浏览器按钮的行为不同：不切 tab 而是开 overlay）
- 删除顶部注释中"Browser was a P5 placeholder that has since been removed"等过时说明，更新为新的竖栏架构说明
- `RightPanelTab` 类型不需要扩展（仍只有 "files"/"git"，浏览器不走 tab 状态）

#### 2. `Titlebar.tsx`（移除浏览器按钮）
- 删除行 200-224 的浏览器 toggle 按钮（`{!isBrowserMode && <button onClick={onToggleBrowser}>...IconWorld...</button>}`）及其角标
- 删除 `IconWorld` 的 import（行 10）—— Titlebar 不再需要
- 删除 `browserPanelOpen`、`onToggleBrowser` 两个 prop（Props 接口行 29、33）以及解构（行 74）
- **保留 `isBrowserMode` 逻辑和"返回工作台"按钮**：浏览器 overlay 打开时仍需从顶栏退出。`isBrowserMode` 改为只依赖 `browserPanelOpen`（但 prop 已删，改为直接从 store 读 `browserPanelOpen`），`showLeftStrip` 仍据此隐藏左侧 toggle。具体：把 `browserPanelOpen` 从 prop 改为 `const browserPanelOpen = useSessionStore((s) => s.browserPanelOpen);`，`isBrowserMode = !!browserPanelOpen && !isSettings` 不变
- 保留 `browserTabCount` 读取吗？不再需要（角标随按钮移走了）—— 可移除行 88 的 `browserTabCount` 读取

#### 3. `App.tsx`（清理 Titlebar props）
- 删掉传给 Titlebar 的 `browserPanelOpen={browserPanelOpen}` 和 `onToggleBrowser={...}` 两个 prop（行 138、142）
- `BrowserPanel` 仍在 App.tsx 行 111 顶层渲染——不动

#### 4. 类型检查与约定
- 改完跑 `cd apps/desktop && npx tsc --noEmit -p tsconfig.json`，确保 Titlebar 的 Props 改动不破坏其他调用点（Titlebar 仅在 App.tsx 被调用两次：workspace 和 settings 模式，settings 模式没传这两个 prop，不受影响）
- 遵循编码约定：用 `cn()` 合并 class、用语义 token（`bg-surface-muted`/`text-accent`/`border-edge`）、用 `<IconX size={20}>` 图标

### 不改动的部分（明确边界）
- `BrowserPanel.tsx`：不动，仍是 `fixed inset-x-0 top-10 bottom-0 z-40` 全屏 overlay
- `FilesPanel.tsx` / `GitPanel.tsx`：不动
- `sessionStore.ts`：`rightPanelTab` / `browserPanelOpen` / `browserTabCount` / `setBrowserPanelOpen` 字段都复用，不动
- `packages/contracts/src/ipc.ts` 的 `RightPanelTabSchema`：不扩展（浏览器不作为 tab 值）
- 顶栏的左/右/底部终端 toggle 按钮、`isBrowserMode` 隐藏逻辑、"返回工作台"按钮：全部保留

### 交互验证清单
1. 点文件图标 → 主面板显示 FilesPanel，图标高亮
2. 点 Git 图标 → 主面板显示 GitPanel，图标高亮
3. 点浏览器图标 → 全屏 overlay 打开（行为同原顶栏按钮）；图标可显示 tab 数角标
4. 浏览器 overlay 打开后，顶栏左侧出现"返回工作台"按钮，点击关闭 overlay 回到工作台
5. 重启后 `rightPanelTab` 持久化生效（仍记得上次选的是文件还是 Git）
6. `openFileInIde` 触发 `ideFocusNonce` → 右栏自动展开（App.tsx 行 99-101），显示当前 tab 的面板
