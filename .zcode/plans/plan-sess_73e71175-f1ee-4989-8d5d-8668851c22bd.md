## 目标
打开 `.md` 文件时默认进入预览状态（渲染后的 Markdown），工具栏提供切换按钮可切回源码编辑状态（Monaco）。

## 现状
- `FileEditor.tsx` 只有两种模式 `edit`（Monaco 编辑）和 `diff`（Monaco DiffEditor），无预览分支。`.md` 文件走 `EditPane`，和普通代码一样在 Monaco 里显示 markdown 源码。
- `ideFileViewModeByProject` 类型为 `Record<projectId, Record<filePath, "edit" | "diff">>`，是 per-project、per-file 的视图模式，未持久化。
- `openFileInIde(filePath, opts)` 打开文件时设置 viewMode：仅在 `opts.diff` 时设 `"diff"`，否则保留已有值（无则默认 `"edit"`）。
- 已有 `components/chat/Markdown.tsx` 的 `Markdown` 组件（react-markdown + remark-gfm + remark-math + rehype-katex + Shiki），但它绑定聊天专用 CSS 变量 `var(--chat-font-size)` 和聊天专用样式，不适合直接用在编辑器区域。

## 方案

### 1. 扩展 viewMode 联合类型：`"edit" | "diff" | "preview"`（sessionStore.ts + ipc.ts）

- `sessionStore.ts:288` 字段类型 `Record<string, Record<string, "edit" | "diff">>` -> `Record<string, Record<string, FileViewMode>>`，其中 `FileViewMode = "edit" | "diff" | "preview"`。
- `setIdeFileViewMode(filePath, mode)` 的 `mode` 参数类型随之扩展（无需改逻辑，已是透传）。
- `openFileInIde` 的 `opts.diff` 逻辑不变（diff 仍优先）；**新增**：首次打开（该 filePath 在 viewMode 中无记录）且是 `.md`/`.markdown` 文件时，默认设为 `"preview"`。这样实现"md 默认预览"，且用户切换到 edit 后再次打开同一文件会保留 edit（因为已有记录）。

### 2. FileEditor.tsx：新增 preview 分支 + 工具栏切换

**effectiveMode 计算**（替换 71-72 行）：从 `"edit" | "diff"` 扩展为 `"edit" | "diff" | "preview"`：
- `historyOnly` -> `"diff"`（历史提交对比，最高优先级，不变）
- 否则 `viewMode === "diff" && diffBefore != null` -> `"diff"`
- 否则 `viewMode === "preview"` -> `"preview"`
- 否则 `"edit"`

**渲染分支**（85-91 行）：新增 preview 分支：
```tsx
{effectiveMode === "diff" && diffBefore != null ? (
  <DiffPane ... />
) : effectiveMode === "preview" ? (
  <MarkdownPreviewPane filePath={filePath} />
) : (
  <EditPane filePath={filePath} />
)}
```

**工具栏**（EditorToolbar）：对 markdown 文件显示"预览/编辑"切换按钮（与现有 diff 切换按钮风格一致，放同一组）：
- 仅当 `isMarkdown(filePath)`（`extname` 为 `.md`/`.markdown`）时显示。
- 当前 `preview` -> 显示"编辑"按钮（IconEdit），点击切 `"edit"`。
- 当前 `edit` -> 显示"预览"按钮（IconEye），点击切 `"preview"`。
- 当前 `diff` 时该按钮显示"预览"（切回 preview），因为 diff 是临时审查态。
- `onTogglePreview` 回调：`setViewMode(filePath, mode === "preview" ? "edit" : "preview")`。

需要给 EditorToolbar 传 `isMarkdown`、`mode`（现已是 `"edit"|"diff"`，扩展为含 `preview`）、`onTogglePreview` 三个新 prop。

### 3. 新增 MarkdownPreviewPane 组件（FileEditor.tsx 内）

复用 EditPane 的文件加载逻辑（`api.file.readFile`），只读渲染。为避免直接耦合聊天专用样式，**直接复用 `Markdown` 组件**但套一个编辑器风格的滚动容器：

```tsx
function MarkdownPreviewPane({ filePath }: { filePath: string }) {
  const [content, setContent] = useState<string | null>(null);
  useEffect(() => {
    let cancelled = false;
    setContent(null);
    api.file.readFile({ filePath })
      .then(({ content }) => { if (!cancelled) setContent(content); })
      .catch(() => { if (!cancelled) setContent(""); });
    return () => { cancelled = true; };
  }, [filePath]);

  if (content === null) {
    return (<div className="flex h-full items-center justify-center gap-1.5 text-[11px] text-content-subtle">
      <IconLoader2 size={12} className="animate-spin" /> 读取文件…
    </div>);
  }
  return (
    <div className="h-full overflow-auto bg-surface px-6 py-4 [font-size:13px]">
      <Markdown>{content}</Markdown>
    </div>
  );
}
```

- 复用 `Markdown`（含 Shiki 代码高亮、GFM、数学公式），用 `px-6 py-4` + `13px` 字号贴合编辑器阅读体验，覆盖其 `var(--chat-font-size)`（外层 `font-size` 会被 `Markdown` 内部 `[font-size:var(--chat-font-size)]` 覆盖，所以需确认--若被覆盖则用一个 wrapper 覆写 CSS 变量 `--chat-font-size: 13px`）。
- 预览是只读的，不涉及保存/dirty 状态。

### 4. 辅助函数
在 FileEditor.tsx 加 `isMarkdown(filePath)`：`const ext = extname(filePath); return ext === ".md" || ext === ".markdown";`（`extname` 已 import）。

## 改动范围
- `apps/desktop/src/renderer/stores/sessionStore.ts`：扩展 viewMode 类型 + `openFileInIde` md 默认 preview 逻辑。
- `apps/desktop/src/renderer/components/ide/FileEditor.tsx`：effectiveMode 含 preview、渲染分支、工具栏切换按钮、新增 MarkdownPreviewPane、isMarkdown 辅助、import Markdown 组件。
- 不改 ipc.ts 的 zod schema（viewMode 不经 IPC 校验，是纯 renderer 状态）。
- 不改 EditPane / DiffPane。

## 验证
1. `npx tsc --noEmit -p tsconfig.json` 通过。
2. 手动验证：打开 `.md` 文件默认显示预览 -> 点"编辑"切到 Monaco 源码 -> 点"预览"切回；打开 `.ts` 文件不显示预览切换按钮、正常编辑；切项目/重开同一 md 文件保留上次模式。
