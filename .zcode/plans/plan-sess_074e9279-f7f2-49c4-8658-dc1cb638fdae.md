重构模型回复的渲染管道，引入虚拟列表、语法高亮、数学公式、React Compiler、useDeferredValue、代码缓存和自适应节流，在不改变用户可见行为的前提下大幅提升长会话性能和代码块可读性。

## 二、分阶段实施细节

### Phase 1: 基础设施（3 个并行无冲突修改）

#### 1.1 React Compiler 配置
- **安装**: `babel-plugin-react-compiler` (devDep) + `react-compiler-runtime` (dep)
- **配置** `electron.vite.config.ts`:
  ```ts
  plugins: [react({
    babel: {
      plugins: [['babel-plugin-react-compiler', {}]],
    },
  })]
  ```
- 渐进启用：chat 组件先加 `"use memo"` 指令，稳定后再全量

#### 1.2 自适应流式节流（`sessionStore.ts`）
- 在 `deltaBuf` 的 `scheduleDeltaFlush` 中引入滑动窗口（最近 5 个 delta 到达间隔）
- 自适应策略：
  - 间隔 < 16ms（密集爆发）→ 保持 rAF（60Hz 批次）
  - 间隔 16-100ms → 50ms 定时器 + rAF 混合
  - 间隔 > 100ms → 下一个 microtask 立即 flush
- 修改 `flushDeltas` 使其能被调度器动态调用

#### 1.3 FNV-1a + LRU 缓存（新文件 `markdownCache.ts`）
- **FNV-1a 哈希**: 纯 JS 实现，无外部依赖
- **LRUCache<K, V>**: 通用 LRU 类，`maxSize=500` + `maxBytes=52MB`
- 两个缓存实例：
  - `codeHtmlCache`: `fnv1a(codeText + lang)` → shiki HTML，代码块专用
  - `mdAstCache`: `fnv1a(markdownText)` → parsed AST，全文 markdown 解析缓存（仅缓存非流式内容，流式由 useDeferredValue 处理）

### Phase 2: Markdown 增强

#### 2.1 语法高亮 + codeDiffs（`Markdown.tsx`）
- 安装 `@shikijs/rehype` + `@shikijs/transformers`
- 创建 lazy highlighter（首次遇到代码块时初始化）：
  ```ts
  import { createHighlighter } from 'shiki'
  import { transformerNotationDiff } from '@shikijs/transformers'
  ```
- 修改 `pre` 自定义组件，将纯文本代码替换为 shiki `codeToHtml` 输出
- 启用 `transformerNotationDiff` 以支持 `// [!code ++]` / `// [!code --]` 语法
- 集成 `codeHtmlCache`：命中缓存时直接返回 HTML，未命中才调用 shiki
- 双主题支持：light/dark 跟随当前色模式

实现细节：
```tsx
// Lazy highlighter singleton
let highlighter: Highlighter | null = null;
async function ensureHighlighter() {
  if (!highlighter) {
    highlighter = await createHighlighter({
      themes: ['github-dark', 'github-light'],
      langs: ['typescript', 'javascript', ...commonLangs],
    });
  }
  return highlighter;
}

// pre component with caching
pre({ children }) {
  const lang = extractLanguage(children);
  const code = extractText(children);
  const cacheKey = fnv1a(code + lang);
  
  const html = useMemo(() => {
    const cached = codeHtmlCache.get(cacheKey);
    if (cached) return cached;
    // ... call shiki codeToHtml, cache result
  }, [code, lang]);
  
  return <div dangerouslySetInnerHTML={{ __html: html }} />;
}
```

#### 2.2 KaTeX 数学公式
- 安装 `katex`, `rehype-katex`, `remark-math`
- 修改 `Markdown.tsx` 的 remark/rehype 链：

  <ReactMarkdown

### Phase 3: 解析降级（`MessageBlocks.tsx`）

修改 `BlockView` 中 text 块的分支：

```tsx
case "text":
  const deferredText = useDeferredValue(block.text);
  const isStale = deferredText !== block.text;
  
  if (isStreamingTail || isStale) {
    // Streaming 或 deferred pending 时：退化到纯文本
    return (
      <div className="whitespace-pre-wrap ...">
        {isStreamingTail ? block.text : deferredText}
      </div>
    );
  }
  // 已稳定 → 完整 Markdown 渲染
  return <Markdown>{deferredText}</Markdown>;
```

这样流式更新时 `block.text` 频繁变化，但 `deferredText` 稳定后才触发昂贵的 markdown 解析。React 18/19 的 `useDeferredValue` 会在空闲时自然追赶。
