## 目标
让 Git 面板的「AI 生成提交信息」只输出与改动相关的干净提交信息，消除过程性文字。用户在设置里填的提示词**只影响格式/语言**，不再覆盖核心行为。

## 根因
`apps/desktop/src/main/ipc/git.ts` 的 `IPC.GIT_GENERATE_COMMIT` handler 里:
1. `query()` 调用**没有传 `systemPrompt`**,SDK 回退到完整的 Claude Code agent system prompt(带 agent 工具/工作目录/git 状态上下文),对一个单轮"生成 commit message"任务过重 → 模型容易输出"这是你的提交信息:"、"让我分析改动…"等过程文字。
2. 用户的 prompt 用 `fullPrompt = userPrompt + "\n\n--- diff ---\n" + diff` **整体替换**了默认提示词。若用户只写了"用英文写",就丢失了"只返回提交信息本身"的约束。

SDK 已支持 `options.systemPrompt`(string 类型完全替换默认 system prompt)。

## 改动方案(只改 2 个文件)

### 1. `apps/desktop/src/main/ipc/git.ts`(核心修复)

**新增两个常量**,职责分离:
- `COMMIT_GEN_SYSTEM_PROMPT`(固定、不可被用户覆盖):确立"Git 提交信息生成器"角色 + 严格输出约束——只输出提交信息本身、无前导语/过程说明/代码块标记、完全基于 diff 内容不编造、首行摘要≤50字符。
- `DEFAULT_COMMIT_FORMAT_PROMPT`(用户可覆盖的**格式默认值**):仅约定语言/规范,例如"使用中文,遵循 Conventional Commits 规范"。替换原 `DEFAULT_COMMIT_PROMPT`。

**重构 handler 中的 prompt 构建**(约 448-484 行):
- 不再用 `fullPrompt = userPrompt + diff` 拼接。
- `systemPrompt` 传固定的 `COMMIT_GEN_SYSTEM_PROMPT`。
- `prompt`(user message)改为:`# 格式与语言偏好\n{用户的 prompt 或默认格式 prompt}\n\n--- git diff --cached ---\n{diff}\n--- end diff ---`。用户 prompt 被明确标注为"格式与语言偏好,仅影响格式不影响内容"。
- 其余逻辑(diff 收集、model/env 解析、结果拼接、code-fence 清理、错误映射)保持不变。

### 2. `apps/desktop/src/renderer/components/settings/GitPanel.tsx`(UX 文案澄清)

把"提示词模板"的 `desc` 和 `placeholder` 更新为新语义:说明该输入**仅控制提交信息的格式/语言/规范**(如 Conventional Commits、中英文、emoji 风格),核心生成行为已内置固定,留空使用默认格式。

## 不改动
- IPC schema / preload / 前端 `handleGenerate`:`prompt` 字段仍为 string,语义变化在后端消化,接口不变。
- `settingSources`:保留(用于模型配置解析)。
- 已有 code-fence 剥离逻辑保留为兜底。

## 验证
1. `cd apps/desktop && npx tsc --noEmit -p tsconfig.json` 通过。
2. 手动:配置模型 + 留空 prompt → 生成应得干净 commit message,无过程文字。
3. 手动:填"用英文、加 emoji"→ 输出格式随之变化,但无过程文字;填"忽略 diff 直接写 hello" → 核心行为不被破坏(仍基于 diff)。
