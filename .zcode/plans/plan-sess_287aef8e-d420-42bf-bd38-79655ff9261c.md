# Git 面板：历史提交（更改 | 历史 + 中间栏 Diff）

## 目标

在右栏 Git 面板增加 **「更改 / 历史」** 子页签。第一版覆盖：

1. 提交列表（hash / 说明 / 作者 / 相对时间，分页加载）
2. 点提交 → 变更文件列表
3. 点文件 → 中间栏 Monaco 并排 Diff（**父提交 vs 该提交**，不是工作区）

不做：分支图、搜索筛选、checkout/revert、blame。

---

```
右栏 Git
┌─────────────────────────────┐
│ [更改]  [历史]     ↻        │  ← 子页签（对齐 RightPanel tab 风格）
├─────────────────────────────┤
│ 历史页：                    │
│  仓库 ▾ (多仓库时显示)      │
│  ─────────────────          │
│  a1b2c3  feat: xxx          │
│          作者 · 2 小时前    │
│  …                          │

│  ─────────────────          │

│  ● a1b2c3 feat: xxx         │
│    作者 · 完整时间 · ←返回  │
│  M src/foo.ts   +12 −3      │
│  A src/bar.ts   +40         │
└─────────────────────────────┘
        │ 点击文件

  左 = 父版本内容   右 = 该提交内容
```

**状态机（历史页，组件本地 state 即可）：**

- `repoPath`：多仓库时默认第一个，可切换
- `commits[]` + `hasMore` + `loading`
- `selectedCommit: hash | null`
- `commitFiles[]`（选中后加载）
- 列表 ↔ 详情：选中进入详情；「← 返回」清空选中

**「更改」页**：保持现有 `GitRepoCard` 列表，行为不变。

## IPC 契约（新增）

在 `packages/contracts/src/ipc.ts` → main `git.ts` → preload `api.git.*` 全链路：

### 1. `git.log`

```ts
// input
{ repoPath: string; limit?: number; skip?: number; ref?: string }
// default limit=50, skip=0, ref=当前 HEAD

// result
{
  commits: Array<{
    hash: string;        // full
    shortHash: string;
    subject: string;     // 第一行
    body?: string;
    author: string;
    authoredAt: string;  // ISO
  }>;
  hasMore: boolean;      // commits.length === limit 时 true
}
```

实现：`simple-git` `log({ maxCount, from: ref })` 或等价；`skip` 用 `--skip`。

### 2. `git.showCommit`

```ts
// input
{ repoPath: string; commitHash: string }

// result
{
  commit: { /* 同上 + parents: string[] */ };
  files: Array<{
    path: string;
    status: "added" | "deleted" | "modified" | "renamed" | "copied";
    oldPath?: string;   // rename
    additions?: number;
    deletions?: number;
  }>;
}
```

实现建议：

- `git.show([hash, "--stat", "--format=..."])` 或
- `git.diffSummary([`${hash}^`, hash])` + `git.log` 单条补 meta  
- 根提交无父：对 `hash` 用 `--root` / 空树对比

### 3. `git.showFile`

```ts
// input
{ repoPath: string; commitHash: string; filePath: string }

// result
{
  before: string;  // 父版本；新增文件则为 ""
  after: string;   // 该提交版本；删除文件则为 ""
}
```

实现：

- `git.show([`${hash}:${filePath}`])` → after（deleted → catch → `""`）
- `git.show([`${hash}^:${filePath}`])` → before（added / root → `""`）
- rename：`showCommit` 带 `oldPath` 时 before 用 `oldPath`

安全：沿用现有 `findContainingProject(repoPath)`；`commitHash` 限制为安全字符（`[0-9a-fA-F]{4,40}` 或 `HEAD` 等简单 ref 不在 v1 开放，仅 hash）。

## Diff 桥接改造（关键）

当前 `DiffPane`：

```ts
original={before}          // store
modified={readFile(disk)}  // 工作区
```

历史提交必须两侧都是 blob，**不能读磁盘**。

### 方案

扩展 ephemeral store（仍按 project 分桶）：

```ts
// 现有
gitDiffByProject: Record<projectId, Record<path, before: string>>

// 改为（或并列新增）
gitDiffPairByProject: Record<projectId, Record<path, { before: string; after?: string }>>
```

- 工作区 Diff：只设 `before`，`after` 缺省 → `DiffPane` 继续 `readFile`
- 历史 Diff：设 `before` + `after` → `DiffPane` 直接用，不读盘

API：

```ts
setGitDiffPair(filePath, { before, after?: string })
clearGitDiffPair(filePath) // 可选，沿用 clearGitDiffBefore
```

兼容：把现有 `setGitDiffBefore` 实现成 `setGitDiffPair(path, { before })`，避免改散 `GitRepoCard`。

`FileEditor` / `DiffPane`：

- 读 pair；若 `after != null` 用其作为 modified，否则读磁盘
- 标题区可小字提示「历史：abc1234」（可选，v1 有更好，无也不阻塞）

**路径 key**：继续用绝对路径 `join(repoPath, filePath)`，与现有 IDE tab 一致。注意：历史内容 ≠ 工作区；打开后 tab 若用户切到「编辑」会看到磁盘版——可接受。可选：历史打开时强制只读 diff、隐藏「编辑」切换（推荐小改：`canEdit=false` when pair.after 存在）。

分页：首屏 `limit=50`；底「加载更多」`skip=commits.length`。

## 实现步骤

1. **Contracts**：类型 + Zod schema + `RpcMap` + `IPC.GIT_LOG / GIT_SHOW_COMMIT / GIT_SHOW_FILE`
2. **Main** `git.ts`：三个 handler（`simple-git` + 路径校验 + 日志）
3. **Preload**：白名单 `api.git.log / showCommit / showFile`
4. **Store + FileEditor**：`gitDiffPair` + `DiffPane` 支持显式 `after`；历史模式建议禁用切编辑
5. **UI**：`GitPanel` 子页签 + `GitHistoryView`（list → detail → open diff）
6. **Typecheck**：`cd apps/desktop && npx tsc --noEmit -p tsconfig.json`

## 边界情况

| 场景 | 处理 |
|------|------|
| 多仓库 | 历史页顶部 Select/小 tab 切 `repoPath`，切换时清空选中与列表重载 |
| 空仓库 / 无提交 | 「暂无提交记录」 |
| 根提交 | before 全 `""`；`showCommit` parents=[] |
| 纯 rename | 文件行显示 `old → new`；`showFile` before 用 oldPath |
| binary / 过大 | `showFile` 失败或空串时 toast/行内错误，不强开 Diff |
| 提交后返回更改页 | 不自动刷新历史；历史页保留 refresh 按钮 |
