# 本轮修改文件区:消息流末尾的 diff 卡片 + 持久化

## 目标
1. 卡片从**输入框上方**(像弹框)移到**消息流末尾**(turn 输出结尾)。
2. 折叠态:文件数 + **改动总数量** `+N -M`。
3. 展开态:每文件一行(路径 + `+n -m` + 占位「审查」按钮 + 展开箭头);再展开单文件显示红绿 diff。
4. 「审查」按钮占位,不实现功能。
5. **本轮修改的文件持久化到 DB**,重开会话仍可见(在原方案基础上新增的需求)。

## diff 数据来源(已确认:复用文件快照,不引入 git)
`FileSnapshot` 已持有轮前内容。`freeze()` 时算出每文件的 adds/dels + 把轮前内容带过 IPC;渲染层用新增 IPC 按需读轮后磁盘内容,再用现有 `lineDiff()` 算完整 diff。

## 文件变更

### A. 持久化(新增需求)

**A1. `packages/contracts/src/session.ts`** — `Session` 类型加 `turnFiles: TurnFileEntry[] | null`(JSON 列,同 contextSnapshot/todos 模式)。
> 字段定义为 `{ filePath, kind, adds, dels, before }[]`,与 turn.files 事件 payload 一致。

**A2. `apps/desktop/src/main/store/db.ts`** — `migrate()` 加 `addColumnIfMissing(database, "sessions", "turn_files", "TEXT")`。

**A3. `apps/desktop/src/main/store/repositories.ts`**:
- `SessionRow` 加 `turn_files: string | null`。
- `rowToSession` 解析 `turnFiles`(safeJson)。
- `SessionRepo.create` 的 INSERT 加 turn_files 列。
- 新增 `SessionRepo.updateTurnFiles(id, files)`:JSON 序列化写入(仿 updateTodos)。

**A4. `apps/desktop/src/main/claude/RuntimeManager.ts`** — `emit()` 里加 `turn.files` 分支调用 `SessionRepo.updateTurnFiles(session.id, e.files)`(紧挨 plan.update 分支)。注意 `turn.rewound` 也要落库(写空数组),否则重载后已撤销的文件又出现。

**A5. `apps/desktop/src/renderer/stores/sessionStore.ts`**:
- 新增 `hydrateTurnFiles(set, get, sessionId)`(仿 hydrateCapsule),从 session row 恢复 `turnFilesBySession[sid]`。
- `selectSession` 里在 `hydrateCapsule` 后调用 `hydrateTurnFiles`。

### B. 扩展 turn.files 事件 payload(diff 统计 + 轮前内容)

**B1. `packages/contracts/src/runtime.ts`** — `TurnFilesEvent.files` 元素扩展:
```ts
files: Array<{
  filePath: string;
  kind: "modified" | "created";
  adds: number;   // freeze 时算好,折叠态直接显示
  dels: number;
  before: string; // 轮前完整内容(modified=原内容; created="")
}>;
```

**B2. `apps/desktop/src/main/lib/fileSnapshot.ts`**:
- `FrozenFile` 加 `adds/dels/before`。
- `freeze()`:对每条 record,读轮后磁盘内容(`readFile`),用**内联的行计数 diff**(只数 adds/dels,不存 diff 行,~25 行 LCS 计数;主进程不依赖 renderer 的 lineDiff)算统计。before = record.content(modified)或 ""(created)。读盘失败/二进制:adds=dels=0,before=""。
- `restore()` 不变。

**B3. `apps/desktop/src/renderer/lib/turnFiles.ts`** — `TurnFileEntry` 加 `adds/dels/before`。

### C. 新增按需读盘 IPC(渲染层算完整 diff 用)

**C1. `packages/contracts/src/ipc.ts`** — 加 `IPC.FILE_READ` 常量 + zod schema `{ filePath: string }` + RpcMap `{ result: string }`。
**C2. `apps/desktop/src/preload/index.ts`** — `api.file.readFile(filePath)` 白名单。
**C3. `apps/desktop/src/main/ipc/files.ts`(新建)** — handler 读盘,**限制在当前项目 cwd 内**(复用 fileSnapshot 的 `safeResolveOk` 安全校验,防越界读任意文件)。在 `main/ipc/index.ts` 注册。

### D. 渲染层:重写卡片 + 改挂载位置

**D1. `apps/desktop/src/renderer/components/chat/DiffView.tsx`(新建)** — 把 MessageBlocks.tsx 里的 `DiffView` + `annotateDiffWithLineNumbers` 抽成独立导出组件,供两边共用。
**D2. `apps/desktop/src/renderer/components/chat/MessageBlocks.tsx`** — 改为从 `./DiffView.js` 导入 DiffView(删除局部定义)。
**D3. `apps/desktop/src/renderer/components/chat/TurnFilesCard.tsx`** — 重写:
- 折叠态:`📝 本轮修改了 N 个文件` + 汇总 `+{总adds} -{总dels}`。
- 展开态:每行 = 图标 + 路径 + `+{adds} -{dels}` + 「审查」按钮(`<Button variant="outline" size="sm">` + `IconEye`,onClick 暂 console.log 占位)+ 展开箭头。
- 展开单文件:`api.file.readFile(filePath)` 取轮后 → `lineDiff(entry.before, after)` → `<DiffView>`。loading 显骨架,created 文件 before="" 即全绿新增。
- 保留「撤销本轮」按钮。
**D4. `apps/desktop/src/renderer/components/chat/ChatPane.tsx`**:
- 删除 459-461 行(输入框上方挂载)。
- 在消息流 `messages.map` 后(`mx-auto max-w-5xl space-y-5` div 内)追加:
  ```tsx
  {turnFiles.length > 0 && !isRunning && (
    <TurnFilesCard files={turnFiles} onRewind={() => void rewindTurn()} />
  )}
  ```
  `!isRunning` 守卫:turn 运行中不显示,结束后才出现。

### E. 类型对齐
store 里 `turn.files` 事件处理(1246 行)的 `e.files` 字段已变多,TS 会自动要求新字段——确保 contracts/runtime.ts、main/fileSnapshot.ts、renderer/turnFiles.ts 三处类型同步。
