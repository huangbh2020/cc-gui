## 二、消息流功能优化

### 2.1 回到底部按钮逻辑修复

**改动文件:** `apps/desktop/src/renderer/components/chat/ChatPane.tsx`

**根因分析:** 当前 `showJumpBottom` 只在 `onScroll` 回调里更新。问题:
- 当内容高度变化(新消息到达 / 流式增长)但用户没滚动时,`onScroll` 可能不触发或触发时 `scrollLength` 尚未更新,导致按钮该出现时不出现、或不该出现时残留。
- `updateJumpState`(448 行)是死代码,从未被调用。

**修复方案:**
1. 删除死代码 `updateJumpState`(448-455 行),只保留 `handleVirtualScroll`。
2. 把 150px 硬编码阈值提取为模块常量 `NEAR_BOTTOM_THRESHOLD = 120`。
3. **关键修复**:在数据变化时也重新计算按钮可见性。新增一个 `useEffect`,依赖 `renderItems`(消息列表)和 `virtualScrollTop`,在每次渲染数据变化后用 `requestAnimationFrame` 调用一次 near-bottom 判定,更新 `showJumpBottom`。这样流式增长 / 新消息到达时按钮状态会正确刷新。
4. 复用 `LegendListState` 的 `scroll` + `scrollLength`(已有,类型已确认存在)。判定逻辑:`scrollLength - scroll > NEAR_BOTTOM_THRESHOLD` → 显示按钮;否则隐藏。空会话(`empty`)时强制隐藏。

### 2.2 用户消息:复制按钮移到右侧 + 悬停显示发送时间

**改动文件:** `apps/desktop/src/renderer/components/chat/ChatPane.tsx`(`MessageRow` + `CopyRow`)

**具体:**
1. **新增时间格式化 helper**(模块级,复用 `fmtClock` 思路但返回完整日期时间):
   ```ts
   function fmtFullDateTime(ms: number): string {
     const d = new Date(ms);
     const pad = (n: number) => String(n).padStart(2, "0");
     return `${d.getFullYear()}-${pad(d.getMonth()+1)}-${pad(d.getDate())} ${pad(d.getHours())}:${pad(d.getMinutes())}:${pad(d.getSeconds())}`;
   }
   ```
2. **`MessageRow` 对用户消息**:
   - 给用户气泡容器(`max-w-[85%]` 那个 div)加 `title={fmtFullDateTime(msg.createdAt)}`(用户已选"完整日期时间 tooltip"方案)— 浏览器原生 tooltip,鼠标悬停气泡即显示发送时间。
3. **`CopyRow` 对用户消息右对齐**:
   - `CopyRow` 接收一个 `align?: "start" | "end"` prop。
   - 用户消息传入 `align="end"`(复制按钮在气泡右侧下方右对齐);助手消息保持 `align="start"`(左对齐,现状)。
   - 实现方式:把 `CopyRow` 的 `justify-start` 改为 `cn("mt-1 flex opacity-0 transition-opacity group-hover:opacity-100", align === "end" ? "justify-end" : "justify-start")`。
   - 在 `MessageRow` 调用处:`{showCopy && <CopyRow text={copyText} align={isUser ? "end" : "start"} />}`。

## 实施顺序与验证

1. 先改 **右侧面板背景**(最小、独立,立即可见)。
2. 再改 **设置面板三件**(用户消息色默认+预设、屏蔽通用 tab、AboutPanel + IPC)。
3. 再改 **消息流三件**(回到底部逻辑、用户消息复制+时间、TurnStatRow)。
4. 每步后跑 `cd apps/desktop && npx tsc --noEmit -p tsconfig.json` 类型检查。

**验证点:**
- 设置面板:用户消息背景色默认显示灰色气泡,有 7 个预设色板可选;通用 tab 不再出现在导航;关于面板显示版本/许可证/仓库链接/复制按钮。
- 消息流:滚动条不在底部时回到底部按钮稳定显示,在底部时隐藏;用户消息复制按钮在右侧,悬停气泡显示完整日期时间 tooltip;"开始/用时"卡片字体变大且有下划线分隔。
- 右侧面板背景与中间面板同色,仅靠 border-l 区分。

所有改动不涉及持久化 schema 变更(用户消息色仍存 "R G B" triplet,默认色变化只影响 styles.css 的 CSS 变量回退值,已存的用户自定义不受影响)。
