让系统品牌色(`--accent`,当前 emerald 绿)可在设置页配置。完全复用现有 `--user-bubble` 的成熟管线(setting key → store → appearance.ts → CSS var),改动面集中在渲染层,**不需要改 main 进程或新增 IPC 通道**。

## 设计决策(取合理默认)

1. **单色,浅色/深色共用** —— 和现有的「用户消息背景色」机制一致。用户选一个颜色,两个主题都用它;未自定义时回落到 `styles.css` 里 `:root`/`.dark` 各自的默认值(emerald-600/500)。这是最小可行方案,改动面最小。
2. **新建独立 `AccentPanel`** —— 品牌色影响全局(按钮/链接/选中态/focus ring),概念上独立于「聊天外观」,单独成块更清晰。
3. **预设色板 + 自由取色** —— 提供一组精选预设色快捷点击,旁边放原生 `<input type="color">` 作为自由取色补充,提升体验。

## 持久化格式

- setting key:`ui.accentColor`(沿用 `ui.*` 命名空间约定)
- 值格式:`"R G B"` triplet 字符串(如 `"5 150 105"`),与 `ui.userMessageColor` 完全一致,直接喂 Tailwind `<alpha-value>` 透明度组合
- 走**通用** `setting.get/set` IPC(已存在,无需新增 handler)
