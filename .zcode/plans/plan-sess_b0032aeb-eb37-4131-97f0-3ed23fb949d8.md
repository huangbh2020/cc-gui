## 设置面板改为独立页面（对齐主页面布局）

### 目标
把设置从居中弹窗改成**独立页面视图**：左侧 280px 菜单 + 右侧内容，复用主页面的标题栏与三栏壳层视觉；没有右侧 IDE 面板；左上角放"返回工作区"按钮。

### 设计要点
- **视图切换复用现有 `settingsOpen` 开关**（store 字段不变，仍不持久化——每次启动回到工作区，符合习惯）。三个入口（LeftBar ⚙、ChatPane CTA、ModelDropdown）零改动，继续调 `setSettingsOpen(true)`。
- **标题栏提取为 `Titlebar` 组件**，用 `mode: "workspace" | "settings"` 区分两种变体，避免 App.tsx 条件嵌套。
- **设置页复用 `ThreePaneLayout`**（`leftOpen=true`、`rightOpen=false`），最大化继承主页面的圆角/分隔/配色，保证"布局基本一致，只是没有右侧面板"。
- **各 Panel 组件原样复用**（ThemePanel / ChatAppearancePanel / DisplayModePanel / ClaudePathPanel / CustomModelsPanel / RadioCard），只换外壳。
- App 顶层 hooks（`useClaudeEvents`/`useTheme`/`useChatAppearance`/`init`）保持在视图分支之前——切到设置页不会中断 claude 事件流与主题同步。

### 文件改动

**1. 新建 `apps/desktop/src/renderer/components/layout/Titlebar.tsx`**
- 导出 `Titlebar`，props：`{ mode: "workspace" | "settings"; leftOpen: boolean; rightOpen: boolean; onToggleLeft?: () => void; onToggleRight?: () => void; onBack?: () => void }`
- 把 App.tsx 现有标题栏 JSX 搬入，按 mode 分支：
  - **workspace**：左 strip 放左栏折叠按钮（`IconLayoutSidebarLeftExpand`），主 strip 放 `<ActiveThreadTitle/>` + 右栏折叠按钮（`IconLayoutSidebarRightExpand`）——与现状完全一致
  - **settings**：左 strip（固定 280px）放"返回工作区"按钮（`IconArrowLeft` + 文字，左对齐），主 strip 放"设置"标题
- 把 `ActiveThreadTitle` 函数一并搬入此文件（仅 workspace 模式用）
- 保留 macOS `pl-[78px]` 红绿灯预留、`WebkitAppRegion` 拖拽/no-drag、Windows `pr-[138px]` 预留
- class 合并用 `cn()`，图标走 `@renderer/lib/icons.js`

**2. 新建 `apps/desktop/src/renderer/components/settings/SettingsPage.tsx`**
- 导出 `SettingsPage`，内部用 `<ThreePaneLayout left={...} center={...} right={null} leftOpen rightOpen={false} />`
- **left slot**（设置菜单）：搬入 `NAV_ITEMS` 和导航按钮逻辑，激活态左侧 `bg-accent` 竖条、`bg-surface-hover` 高亮，class 全部改用 `cn()`
- **center slot**（内容区）：`<div className="min-h-0 flex-1 overflow-y-auto px-6 py-5">`，按 `active` 渲染对应 Panel（含 `appearance` 组合面板与 `PlaceholderPanel`）
- `PlaceholderPanel` 函数从 SettingsModal 搬过来
- Esc 键绑定 `setSettingsOpen(false)` 返回工作区（保留原快捷键习惯）
- 默认 `active="claude-path"`（与原弹窗一致）

**3. 删除 `apps/desktop/src/renderer/components/settings/SettingsModal.tsx`**
- 内容已被 SettingsPage + Titlebar 完全替代，删除避免混淆

**4. 改 `apps/desktop/src/renderer/App.tsx`**
- 引入 `Titlebar`、`SettingsPage`，订阅 `settingsOpen`/`setSettingsOpen`
- 顶层 hooks 位置不变；return 内根据 `settingsOpen` 分支：
  ```
  settingsOpen === true:
    <Titlebar mode="settings" leftOpen rightOpen={false} onBack={() => setSettingsOpen(false)} />
    <SettingsPage />
  settingsOpen === false:
    <Titlebar mode="workspace" leftOpen={leftOpen} rightOpen={rightOpen} onToggleLeft onToggleRight />
    <div className="relative flex min-h-0 flex-1 bg-surface-muted">
      <ThreePaneLayout left={<LeftBar/>} center={<CenterPane/>} right={<RightPanel/>} leftOpen rightOpen />
    </div>
  ```
- 删除原内联标题栏 JSX、`ActiveThreadTitle` 函数（已搬入 Titlebar）、`<SettingsModal/>` 挂载
- `leftOpen`/`rightOpen` state 保留在工作区分支（设置页不使用）

### 不变的部分
- store 的 `settingsOpen`/`setSettingsOpen` 字段与签名
- 所有 Panel 组件、RadioCard、setting 持久化链路（`api.setting.get/set` → SettingRepo → SQLite）
- LeftBar ⚙ 按钮、ChatPane CTA、ModelDropdown 三个入口
- CSS 变量同步（`useChatAppearance` 仍挂载在 App 根，设置页改字体/颜色实时生效）
