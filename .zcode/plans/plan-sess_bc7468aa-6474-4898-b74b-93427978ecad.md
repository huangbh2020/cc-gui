## 一、打包配置(electron-builder)

## 二、自动更新(electron-updater,GitHub Releases)

### 2.1 安装依赖
`apps/desktop` 添加 `electron-updater` 为 dependency。

### 2.2 契约层(`packages/contracts/src/ipc.ts`)
- 新增推送消息类型:
  ```ts
  export interface UpdateAvailableMessage {
    channel: "update:available";
    version: string;        // 新版本号
    releaseNotes?: string;  // release notes(可为空)
    releaseDate?: string;
  }
  export interface UpdateDownloadedMessage {
    channel: "update:downloaded";
    version: string;
    releaseNotes?: string;
  }
  ```
- 加入 `MainToRendererMessage` 联合
- `RpcMap` 新增:
  ```ts
  "app.checkForUpdates": () => Promise<{ status: "up-to-date" | "available" | "error"; version?: string; error?: string }>;
  "app.downloadUpdate": () => Promise<void>;
  "app.quitAndInstall": () => Promise<void>;
  ```
- `IPC` 常量新增:`APP_CHECK_FOR_UPDATES`、`APP_DOWNLOAD_UPDATE`、`APP_QUIT_AND_INSTALL`、`UPDATE_AVAILABLE`、`UPDATE_DOWNLOADED`

### 2.3 主进程更新模块(新建 `apps/desktop/src/main/updater.ts`)
封装 autoUpdater 逻辑:
- `initUpdater()`:在 `app.whenReady` 中 `createMainWindow()` 之后调用
  - 设置 `autoUpdater.autoDownload = false`(由用户手动触发下载,避免静默下载)
  - 设置 `autoUpdater.autoInstallOnAppQuit = true`
  - 监听 `update-available` → `sendToRenderer(IPC.UPDATE_AVAILABLE, { channel, version, releaseNotes, releaseDate })`
  - 监听 `update-downloaded` → `sendToRenderer(IPC.UPDATE_DOWNLOADED, { channel, version, releaseNotes })`
  - 监听 `error` → `log.error(...)`
  - **dev 环境跳过**(electron-updater 仅在打包后 app.asar 内生效,dev 下检查会报错;用 `is.prod` 守卫)
  - 启动后延迟 10s 自动检查一次(`autoUpdater.checkForUpdates()`),之后每 4 小时检查一次(setInterval)
- 导出 `checkForUpdates()` / `downloadUpdate()` / `quitAndInstall()` 供 IPC handler 调用
- 所有操作 try/catch 包裹,失败只 log 不抛(更新功能不能影响主功能)

### 2.4 IPC handler(新建 `apps/desktop/src/main/ipc/updater.ts`)
```ts
export function registerUpdaterHandlers(ipcMain: IpcMain): void {
  ipcMain.handle(IPC.APP_CHECK_FOR_UPDATES, async () => { ... });
  ipcMain.handle(IPC.APP_DOWNLOAD_UPDATE, async () => { ... });
  ipcMain.handle(IPC.APP_QUIT_AND_INSTALL, async () => { ... });
}
```
在 `ipc/index.ts` 注册。

### 2.5 启动挂载(`apps/desktop/src/main/index.ts`)
`whenReady` 回调内,`createMainWindow()` 之后加 `initUpdater()`。

### 2.6 preload 白名单(`apps/desktop/src/preload/index.ts`)
- `app` 命名空间新增 `checkForUpdates` / `downloadUpdate` / `quitAndInstall`
- `on` 下新增 `updateAvailable` / `updateDownloaded` 订阅(照抄 `themeChanged` 模板)

### 2.7 UI(`apps/desktop/src/renderer/components/settings/AboutPanel.tsx`)
改造现有"检查更新"按钮:
- onClick 从 `openExternal(RELEASES_URL)` 改为 `api.app.checkForUpdates()`
- mount 时订阅 `api.on.updateAvailable`,有更新时在按钮区显示通知条(新版本号 + "立即下载"按钮)
- 订阅 `api.on.updateDownloaded`,显示"重启安装"按钮(调 `api.app.quitAndInstall()`)
- 用本地 state 管理:`updateState: "idle" | "checking" | "available" | "downloading" | "downloaded" | "error"`
- 更正 `REPO_URL` 为真实仓库 `https://github.com/huangbh2020/cc-gui`
- 遵循项目 UI 规范:用 `cn()` + 语义 token + base-ui `<Button>` + tabler 图标

## 三、CI/CD(GitHub Actions)

### 3.1 新建 `.github/workflows/ci.yml`(PR/push 质量门禁)
- 触发:`push` 到 master、所有 PR
- job `quality`:ubuntu-latest,Node 20,pnpm 9
  - `pnpm install`
  - `pnpm typecheck`(turbo run typecheck)
  - (本次不跑 test,因未引入 vitest)

### 3.2 新建 `.github/workflows/release.yml`(打 tag 自动发布)
- 触发:push tag `v*.*.*`
- matrix:macos-latest(arm64+x64)、windows-latest(x64)
- 步骤:
  - checkout、setup-node 20、setup-pnpm 9
  - `pnpm install`
  - `pnpm rebuild:native`(node-pty 对应平台 ABI;macOS arm64 runner 原生支持)
  - `pnpm package`(electron-vite build + electron-builder)
  - 用 `softprops/action-gh-release@v2` 上传产物到 GitHub Releases
    - macOS: `.dmg`、`.zip`、`latest-mac.yml`
    - Windows: `.exe`(nsis)、`latest.yml`
    - **包含 `latest*.yml` 是 electron-updater 能检查更新的关键**
- 不配签名(暂不签名)
- 用 `GITHUB_TOKEN`(action-gh-release 自动识别)即可发布,无需额外 secret

### 3.3 turbo 任务调整
- `turbo.json` 的 `package` 任务设 `cache: false`(打包产物大且平台相关,不缓存)
- 根 `package.json` 补 `"package": "turbo run package"`
